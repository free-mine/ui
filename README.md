# Free Mine UI

Интерфейс для работы пользователей с организацией https://github.com/free-mine. Представляет собой собираемый фронтенд, для дальнейшей публикации директории `dist` на сервере.

## Работа с сервером

Интерфейс взаимодействует с сервером из репозитория https://github.com/free-mine/server. Локально этот репозиторий находится в соседней директории, так что можно запускать его в Docker для помощи в разработке.

## Работа с блокчейном

Некоторые операции (например, покупка `MagicOre`) требуют подписания транзакции от имени пользователя. Соответственно, необходима интеграция с браузерными кошельками, такими как MetaMask, Rabby и т.д. Работа с ними должна быть удобной. Вся работа происходит строго в сети Avalanche C-Chain.

## Функциональность

Интерфейс позволяет видеть свой баланс токена `MagicOre`, текущего доллара `FreeMine`, покупать `MagicOre` за доллар, а также управлять заявками на вывод.

В интерфейсе можно наблюдать за размещением капитала в контракте `OreVein`. Каждая торговая пара должна иметь ссылку на Uniswap, позволяющую рассмотреть эту торговую пару в интерфейсе Uniswap. Для ознакомление с портфелем Фонда целиком в независимом источнике интерфейс предоставляет ссылку на DeBank.

Все публичные агрегированные данные от сервера должны иметь отражение в интерфейсе.

## Дизайн

Создай уникальный брендовый дизайн для UI инвестиционного Фонда. Не ставь точку после текста заголовка любого уровня. Не добавляй бессмысленных мотивационных фраз. Интерфейс должен быть удобным, не перегруженным и привлекательным.

## Технологии

Технологии фронтенда делаем аналогичными https://github.com/free-mine/admin-panel:
- SCSS;
- TypeScript;
- ESLint + Prettier + StyleLint.
Docker в этот репозиторий не тащим! Только фронтенд.

По поводу реактивной библиотеки: в Admin Panel используется SolidJs, но ты можешь выбрать другую, если для неё будет удобнее сделать интеграцию кошельков.

Также сделай GitHub Workflows CI на Pull Requests. Только актуальные версии, без ворнингов.
